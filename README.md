## 🚀 Featured Projects

### 💜 Mentiva — Mentorship Management Platform

A web application designed to support mentorship programmes through dedicated dashboards and tools for managing mentorship activities.

* 👥 Mentor and mentee dashboards
* 📅 Session management and scheduling
* 🎯 Task and milestone tracking
* 🔐 Authentication and role-based access

**Tech Stack:** React, JavaScript, Node.js, Express.js, MongoDB.

### 📊 MentorTracker — Mentorship Tracking Application

A full-stack application designed to organize mentorship activities and monitor progress between mentors and mentees.

* 📅 Session scheduling and management
* ✅ Attendance and task tracking
* 🎯 Milestone and progress monitoring
* 🔗 Frontend-backend API integration

**Tech Stack:** React, JavaScript, Node.js, Express.js, MongoDB.
